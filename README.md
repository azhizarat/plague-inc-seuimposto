# ☣️ Plague Inc. Brasil 2026 — Tema para `seuimposto.com`

Transforma o painel de apuração presidencial de [`https://seuimposto.com/#presidente`](https://seuimposto.com/#presidente) em uma partida de **Plague Inc.** (**☣️ Patógeno Vermelho / Infectados** vs **🧪 Esforço Global de Cura / OMS**), com manchetes de notícias mundiais, radar de contágio e bolhas clicáveis de **DNA** e **Cura** pelo mapa do Brasil.

![Preview do Tema Plague Inc.](preview.png)

---

## 🚀 Opção 1: Instalar com 1 Clique (UserScript — Recomendado)

1. Instale a extensão [Violentmonkey](https://violentmonkey.github.io/) ou [Tampermonkey](https://www.tampermonkey.net/) no seu navegador (Chrome, Firefox, Edge, Brave).
2. **[👉 Clique aqui para instalar o UserScript (`plague-inc-seuimposto.user.js`)](https://raw.githubusercontent.com/azhizarat/plague-inc-seuimposto/main/plague-inc-seuimposto.user.js)**
3. Confirme a instalação e abra [`https://seuimposto.com/#presidente`](https://seuimposto.com/#presidente).

---

## 🧩 Opção 2: Instalar como Extensão no Chrome / Brave / Edge

1. Baixe este repositório (ou o arquivo [`plague-inc-seuimposto-extension.zip`](https://github.com/azhizarat/plague-inc-seuimposto/raw/main/plague-inc-seuimposto-extension.zip) e extraia em uma pasta).
2. Abra `chrome://extensions/` na barra de endereços.
3. Ative a chave **Modo do desenvolvedor** (canto superior direito).
4. Clique em **Carregar sem compactação** (*Load unpacked*) e selecione a pasta do projeto.
5. Acesse [`https://seuimposto.com/#presidente`](https://seuimposto.com/#presidente).

---

## 🦊 Opção 3: Instalar como Extensão no Firefox

1. Baixe o arquivo [`plague-inc-seuimposto-extension.zip`](https://github.com/azhizarat/plague-inc-seuimposto/raw/main/plague-inc-seuimposto-extension.zip) (ou clone este repositório).
2. Abra `about:debugging#/runtime/this-firefox` na barra de endereços.
3. Clique em **Carregar extensão temporária...** (*Load Temporary Add-on...*).
4. Selecione o arquivo `plague-inc-seuimposto-extension.zip` (ou o `manifest.json`).
5. Acesse [`https://seuimposto.com/#presidente`](https://seuimposto.com/#presidente).
